# 从预览到 v1

## 公开预览前

- [ ] 只发布独立导出目录；人工检查文件清单与隐私扫描结果。
- [ ] 空目录安装、初始化、连接和退出重开通过；不携带开发者个人资料。
- [ ] 更新版本说明及安装包校验值，区分源码发布和应用分发。
- [ ] 公布已测试平台；完成应用发布签名、公证与新电脑安装，或清楚限定为源码预览。
- [ ] 仓库建立后配置私密安全反馈渠道，更新 SECURITY.md。
- [ ] 核对 MIT 与第三方依赖许可证保留情况。

## v1.0 门槛（建议，不是已通过）

- [ ] 3–5 位独立试用者用自己的非敏感项目，按一页说明首次连接。
- [ ] 每人至少两次 AI 切换：读取 → 实际工作 → 草稿返回 → 检查保存 → 换 AI 续做。
- [ ] 剩余事项和失败经历能接续；已废止的要求不冒充当前要求。
- [ ] 权限拒绝、AI 缺失、打开失败、结果未返回、版本变化均有可恢复路径。
- [ ] 重复提交、重启、升级及备份恢复不丢记录或重复保存；保留真实验证记录。
- [ ] 安装包与文档不依赖开发者路径、账号或已有配置。
- [ ] 发布声明与实际支持范围一致；没有把回执、模拟测试或 AI 观察当成用户验收。

这一清单不是完成声明。具体检查结果按版本记录，未做的保持未勾选。
