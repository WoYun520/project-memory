# 记忆站 · Project Memory

在 Codex 与 Claude Code 之间切换时，把项目目标、有效要求、进度和失败经历接过去。工作继续在原 AI 工具中，记忆站保存经过检查的项目记录。

**0.39 开源预览版 · MIT · 本机优先。** 这是早期预览，不是已完成所有场景验收的 v1.0。桌面构建目标为 Apple Silicon Mac、macOS 13 或更新版本。普通 Claude 桌面聊天不在本轮支持承诺内。

**下载：** [Mac 预览版与源码附件](https://github.com/WoYun520/project-memory/releases/tag/v0.39.0-preview) · [反馈问题](https://github.com/WoYun520/project-memory/issues)

**第一次用？先看 [通俗上手说明](docs/start-here.md)：从安装到换 AI，按页面按钮一步步来。**

## 第一次使用

1. 打开记忆站，点「连接第一个项目」，选择你正在做的项目文件夹。
2. 选择 Codex 或 Claude Code，点「连接并启用接续」。已有项目规则会保留；将添加本项目的记忆读取与草稿提交指引。
3. 写一句这次要做的事，交给 AI。Codex 需要把已复制的说明粘贴发送一次；Claude Code 会带着任务在终端启动，登录和项目授权仍在原工具中完成。

AI 返回记录后，回记忆站点「查看新记录」，检查保存。下次换 AI 读取最新保存版本；草稿不自动成为正式记忆。也可以保存时明确选择任务已完成，或保留剩余事项。

没有安装 AI？先在原工具完成安装和登录。记忆站可以先建立项目，但不会代你安装、登录或购买模型服务。系统访问提示需要你在 Mac 上处理。

详细步骤与故障处理见 [快速开始](docs/quick-start.md)。只想体验时，用 [虚构计时器项目](examples/timer/README.md)，不要拿密码、真实服务器配置或私人聊天测试。

## 安装与运行

**Mac 应用：** 从上方版本发布页面下载 `Memory-Station-0.39.0-mac-arm64.zip`，解压后将 `记忆站.app` 放入你的「应用程序」文件夹并打开。应用自带运行组件；不需要为运行应用安装 Node。预览构建默认是本机签名，尚未完成 Developer ID 签名与 Apple 公证，其他电脑可能被系统拦截。不要关闭系统保护；不愿处理未公证应用时使用源码方式。当前本地打包成功不代表其他电脑安装已通过。

**从源码运行：** 需要 Node.js 22.12 或更新版本及 npm。在仓库根目录执行：

```sh
cd station
npm ci
npm run build
npm start
```

打开 <http://127.0.0.1:4180>。网页模式没有原生文件夹选择器，可让当前本机 AI 送来项目位置，或展开手动填写路径。默认档案写入 `station/data/`，不要提交这个目录。退出启动终端会停止源码服务。

Mac 应用默认把档案放在用户的 `Library/Application Support/Project Memory/data`。已有用户继续使用原来配置的位置。关闭应用窗口仍在后台运行，退出应用才停止自启动服务。不要同时运行应用版和另一份使用不同资料库的源码服务占用同一端口。

## 能做什么

- 连接本机项目，给 Codex / Claude Code 提供最新记忆和任务交接。
- 区分 AI 建议、观察结果、人工确认、失效和冲突；原始依据与摘要分开保留。
- 先读简报，再按任务查相关记录；检索仍以文字匹配和明确关联为主。
- 接收待检查草稿，人工保存；记录剩余事项、完成状态及任务历史。
- 导出项目备份、导入为新项目；已保存来源可检查变化。

不自动抓取所有聊天，不保证 AI 主动遵守指引或准确理解，不自动批准 AI 输出，也不提供跨电脑云同步。其他 AI 的手动接入及 Grok 辅助整理是扩展能力，不属于本轮双 AI 主流程保证。

## 隐私与发布边界

密码、密钥和隐私原件禁止进入记忆、依据、草稿、备份与交接。规则检查只能识别部分模式，用户仍须检查材料。连接项目不自动导入全文。记忆由你选择的外部 AI 读取后，可能按该 AI 服务的规则发送到其模型服务；“本机保存”不等于“所有模型离线运行”。

本机接口仅绑定回环地址，不应暴露到公网；同机进程不是隔离的多用户安全边界。见 [隐私说明](docs/privacy.md)、[已知限制](docs/known-limitations.md) 和 [安全问题说明](SECURITY.md)。

开发与构建见 [贡献指南](CONTRIBUTING.md)，v1 门槛见 [发布清单](docs/release-checklist.md)。源码采用 [MIT](LICENSE)；第三方依赖保留各自许可证。
