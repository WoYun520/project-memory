# 0.39 预览版的边界

- 桌面构建限定 Apple Silicon 与 macOS 13+；没有 Windows、Linux 桌面或 Intel Mac 验收。
- 默认应用构建是本机签名，未完成 Developer ID 发布签名和 Apple 公证。新电脑可能拒绝打开，更新也可能重新请求文件访问。构建验证不能代替干净系统安装验收。
- Codex 需要粘贴发送一次；Claude Code 的模型登录、组织权限、额度与系统授权需用户处理。配置指引不保证每个 AI 都会执行。
- 本轮主要支持 Codex 桌面与 Claude Code 终端。普通 Claude 桌面入口即使在代码中保留，也不属于已验证范围。
- 记忆检索使用文字与显式关联，不保证所有任务都召回必要材料；没有材料时应声明未知。
- 原始依据保留不等于事实真实；AI 核查、保存、读取回执与用户验收彼此独立。
- 本机 API 不提供对同机恶意进程的身份隔离，不适合直接开放到公网或多人共享服务器。
- 隐私识别不完整，未实现跨历史、备份和外部副本的一键清理。
- 项目备份不含待检查草稿，导入新项目后需重配本机接入；它不是整机灾难恢复方案。
- 自动检查、隔离示例和本机界面观察不等于陌生用户已成功使用。v1 前还需要独立用户试用。
